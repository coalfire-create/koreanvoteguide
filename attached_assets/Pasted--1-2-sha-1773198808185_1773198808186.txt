앱에 유권자들이 의견을 나눌 수 있는 '커뮤니티' 페이지를 추가해 줘.
1. 하단 네비게이션에 '커뮤니티' 탭을 추가하고 이동할 수 있게 연결해.
2. 커뮤니티 메인 화면은 shadcn/ui의 Card 컴포넌트를 사용해서 게시글 목록을 보여줘. 각 게시글 카드에는 제목, 본문 미리보기, 좋아요/싫어요 수, 댓글 수가 표시되어야 해.
3. 작성자 이름은 모두 '익명의 유권자'로 통일해서 보여줘.
4. 화면 우측 하단에 플로팅 버튼(FAB)이나 상단에 눈에 띄는 '글쓰기' 버튼을 배치해 줘. 전체적인 디자인은 Tailwind CSS로 깔끔하고 가독성 좋게 만들어.

커뮤니티 기능에 '본인인증 기반 익명 시스템'을 도입할 거야.
1. 사용자가 커뮤니티 탭에 들어가거나 '글쓰기' 버튼을 누를 때, 로그인/본인인증이 되어있지 않다면 접근을 막고 "안전한 커뮤니티 조성을 위해 본인인증이 필요합니다"라는 메시지와 함께 인증 페이지로 리다이렉트 시켜 줘.
2. 인증 페이지의 UI를 만들어 줘. 휴대폰 인증이나 이메일 인증 버튼이 중앙에 배치된 깔끔한 화면이면 돼.
3. 사용자가 인증을 완료하면, DB에 실제 개인정보는 안전하게 저장하되, 커뮤니티에서 활동할 때는 '정의로운 올빼미 #102', '깨어있는 시민 #405' 처럼 랜덤한 익명 닉네임이 자동으로 부여되도록 로직을 작성해 줘.
3단계: 커뮤니티 상세 기능 (투표 및 토론)
단순한 게시판을 넘어, 정치 앱에 맞는 기능적인 요소를 추가합니다.
커뮤니티 게시글 상세 페이지를 구현해 줘.
1. 특정 정책이나 국회의원의 행보에 대해 토론할 수 있도록, 게시글 상단에 찬성/반대 비율을 보여주는 Progress 바를 추가해 줘.
2. 댓글 기능도 추가해 주는데, 게시글 작성자가 단 댓글은 '익명(글쓴이)'로 눈에 띄게 뱃지(Badge)를 달아 줘.
3. 신고하기 버튼을 드롭다운(DropdownMenu)으로 넣어서 부적절한 게시글을 관리할 수 있는 UI를 마련해 줘.


1. 미니멀리즘 홈 화면 (검색 집중형)
* 메인 화면의 기존 파란색 히어로 섹션과 복잡한 정보 카드들을 모두 지우고, 구글 메인 화면처럼 아주 깔끔하게 만들어 줘.
* 배경은 순백색(bg-white)으로 설정하고, 화면 중앙에 앱 로고(타이틀)와 커다란 검색창(Input) 딱 하나만 배치해 줘. 상하좌우 여백을 아주 넉넉하게 줘서 시선이 분산되지 않게 해.
* 검색창의 placeholder는 "내 지역구 국회의원 이름이나 동네를 검색해 보세요"로 설정하고, 옅은 그림자(shadow-md)를 넣어 입체감을 살려 줘.
2. 네비게이션 및 메뉴 간소화 (다이어트)
* 하단 네비게이션(bottom-nav.tsx)의 탭을 '홈', '커뮤니티', '더보기' 딱 3개로만 줄여서 직관적으로 만들어 줘.
* 기존에 있던 '국회의원', '후보자', '법안', '평가' 등의 상세 메뉴들은 화면 밖으로 꺼내지 말고, shadcn/ui의 Sheet (또는 Drawer) 컴포넌트를 사용해서 우측 상단 햄버거 버튼(≡)을 누르면 나오는 슬라이드 사이드바 안으로 깔끔하게 숨겨 줘.
3. 인증 기반 익명 커뮤니티 시스템 구축
* 하단 탭과 연결된 '커뮤니티' 페이지를 만들어 줘.
* 데이터베이스와 인증은 Supabase를 기준으로 구성한다고 가정해 줘. 사용자가 게시판에 들어가거나 '글쓰기'를 누를 때, 로그인(본인인증)이 안 되어 있다면 접근을 막고 로그인 페이지로 이동시켜 줘.
* 단, 실제 커뮤니티 게시글 목록과 상세 페이지(Card 컴포넌트 활용)에서는 작성자의 실제 정보가 노출되지 않고 '익명의 유권자 #123'처럼 자동 생성된 닉네임만 보이도록 프론트엔드 UI를 구성해 줘.
* 게시글 안에는 특정 이슈에 대한 사람들의 의견을 한눈에 볼 수 있도록 찬성/반대 비율을 나타내는 Progress바를 넣어 줘.
4. 국회의원 데이터 직관적 시각화
* 검색을 통해 들어가는 국회의원 상세/평가 페이지는 텍스트 위주가 아니라 시각적으로 구성해 줘.
* 출석률 데이터는 Progress 바를 사용하되, 90% 이상은 초록색, 70% 이하는 빨간색 계열로 조건부 스타일링을 적용해 줘.
* 법안 투표 기록은 shadcn/ui의 Badge 컴포넌트를 사용해서 [찬성]은 파란색, [반대]는 빨간색, [기권/불출석]은 회색으로 명확히 구분되게 렌더링해 줘.
